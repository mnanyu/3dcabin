这座小屋收集什么

最后更新：2026-10-20

林间小屋是一个匿名钓鱼小站。不需要注册，不收集真实姓名，也没有广告追踪。下面说明服务器会保存哪些数据、为什么保存、保存多久。

1. 收集的数据

  • 匿名浏览器 ID：服务器写入一个 HttpOnly Cookie，用来区分不同浏览器，记住你的背包。
  • 钓客称呼：你自己填写的昵称，可以不填。
  • 渔获记录：鱼种、长度、时间，用来显示背包、榜单和图鉴。
  • 每日目标与连续天数：目标鱼、目标数量、进度和连续完成天数，用来显示每日玩法。
  • 最近 IP：用于后台安全、统计和 IP 地理位置解析。
  • IP 地理位置：国家/地区/城市/运营商，由第三方 IP 库解析，精度到城市，不保证准确。
  • 反馈：你主动提交的反馈内容、可选联系方式、页面地址和提交 IP。
  • 服务器访问日志：Nginx/系统日志会记录 IP、时间、路径和状态码，用于安全和故障排查。

2. 用途

  • 记住同一个浏览器，显示你的背包和称呼
  • 生成娱乐性质的渔获榜单和图鉴
  • 记录每日目标进度和连续钓鱼天数
  • 防止刷接口和滥用后台
  • 接收并回复你的反馈

3. 保留期限

  • 有渔获的用户：渔获和用户记录保留 6 个月（按最近渔获滚动）
  • 有称呼但无渔获：保留 3 个月（按最近活跃滚动）
  • 无称呼且无渔获：保留 1 个月（按最近活跃滚动）
  • IP 地理缓存：90 天
  • 反馈和后台审计日志：180 天

公开背包和榜单展示最近 30 天；数据库保留期限可能更长。过期数据会由定时任务清理。

4. 第三方

  • ip-api.com / ipinfo.io：用最近 IP 解析城市级地理位置。
  • FormSubmit：把反馈内容转发到站长邮箱。
  • Cloudflare：站点接入 Cloudflare 后，流量会经过 Cloudflare 的边缘网络。

这些服务会看到完成对应功能所必需的信息。本站不出售数据，也没有广告追踪。

5. Cookie

本站只使用必要的匿名身份 Cookie 和后台登录 Cookie，不使用广告 Cookie。清除浏览器 Cookie 后，服务器会把你当作新的匿名访客。

6. 删除数据

你可以发邮件到 you@example.com，说明要删除的浏览器/称呼和大概访问时间。站长也可以在后台删除对应用户及其渔获。删除后无法恢复。

如果只是不想被记录 IP，可以在浏览器或网络层使用代理/VPN；但这会影响 GeoIP 的准确性，也可能影响后台安全判断。
