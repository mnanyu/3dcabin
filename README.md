# 林间小屋 · 程序化 3D 森林

> 公开仓库版本：联系方式、后台路径和服务器部署细节已替换为占位符。线上站点不在此仓库中。


一个完全由代码生成的 3D 森林小屋场景，带池塘、木码头、小渔夫、第一视角钓鱼、服务器背包和独立渔获榜。没有外部模型、没有贴图文件、没有素材包 —— 木屋、松树、地形、石材、屋顶木瓦、人物、水面、窗光、烟雾、萤火虫和夜空，全部在浏览器里实时生成。

## 打开方式

### 方式一：直接打开单文件版（推荐）

双击 **`林间小屋-单文件版.html`**，或双击 **`打开森林小屋.bat`**。

这是一个约 0.8 MB 的独立 HTML 文件，Three.js 与全部场景代码已经内联。场景和钓鱼离线也能运行，但背包数据需要连接服务器。

### 方式二：开发模式

```bash
npm start
```

然后打开 <http://127.0.0.1:4173>。

> 源码版使用 ES Module 与 importmap，请通过本地服务器打开，不要直接双击 `index.html`。

## 场景里有什么

- **木屋**：逐根排布的原木墙、真实开洞的门窗、石砌基座与烟囱、木瓦屋顶、阁楼圆窗、门廊、长凳、壁灯、柴堆与斧头
- **池塘与码头**：下凹式池塘、动态水面着色器、木栈道、系船灯、钓具篮、踏石支路、芦苇、睡莲与岸边石块
- **小渔夫**：程序化低多边形人物，针织帽、围巾、雨衣、卷线器和可抛投的鱼竿
- **钓鱼背包**：服务器匿名用户记录、每一条鱼的种类/尺寸/时间、30 天展示窗口、自定义称呼；数据按 6/3/1 个月分层保留
- **第一视角**：抛竿后从渔夫眼睛看向浮标，成功上鱼才自动切回原视角；脱钩会留在第一视角继续钓
- **独立面板**：背包和全站渔获榜拆成两个入口，互不混在一起
- **联系方式**：左上角「联系我」面板，包含 GitHub、QQ、微信、邮箱和手机号位
- **后台管理**：`/<admin-path>/` 可查看匿名用户、最近 IP / 地理位置、30 天统计、背包明细和用户反馈，并修改称呼、删除单条渔获或用户
- **意见反馈**：右上角「反馈」把内容发到 `you@example.com`，同时入库；邮箱未激活或发送失败时反馈也不会丢，后台能看到状态
- **森林**：40+ 棵程序化松树、金色阔叶树、灌木、蕨类、蘑菇、野花、石块与踏石小径
- **氛围**：渐变暮色天空、星星、月亮、远山剪影、烟囱烟雾、萤火虫、暖色窗光与门廊灯光池
- **材质**：木纹、木瓦、石材、地面噪点均由 Canvas 2D 代码实时绘制

场景约 **6.8 万三角面**、1250+ 个网格对象、11 盏灯，其中一盏带实时阴影。移动端会自动限制像素比，竖屏时自动放宽视野并拉远构图。

## 背包与服务器数据

- 每个浏览器第一次打开时，服务器会生成一条独立的匿名用户数据（HttpOnly Cookie 身份，不需要注册）
- 同一个浏览器再次访问会继续使用同一条用户记录；即使没有设置称呼，背包和访问记录也会保留
- 每次访问都会记录最近一次请求的 IP 到用户记录，后台管理页可以查看和搜索；IP 不会展示给普通访客
- 每次钓到鱼都会写入服务器 SQLite，背包记录包含鱼种、长度和上钩时间
- 背包和榜单**展示最近 30 天**；服务器数据按活跃度保留：有渔获 6 个月，有称呼无渔获 3 个月，无称呼无渔获 1 个月；每天 04:20 自动清理
- 可以在「背包」面板里设置钓客称呼、查看鱼种统计；全站榜在独立的「榜单」面板
- 钓客称呼不能重复（忽略英文大小写），留空仍显示「无名钓客」；重复时后端返回 409，背包面板就地提示
- 后台会按最近 IP 自动解析国家/地区/城市和运营商，解析结果缓存 7 天，只在后台显示
- 旧版本的本地 `forest-cabin-memory-v1` 身份会在首次打开时自动认领到服务器，然后删除本地副本；之前已同步到服务器的历史渔获会保留
- 不再使用离线本地背包；API 不可达时背包面板会提示未连接，场景和钓鱼本身仍可运行
- 线上服务：`forest-cabin-api.service`，监听 `127.0.0.1:8765`，由 nginx 反向代理到 `/api/fishing/`
- 后台：`/<admin-path>/`（旧 `/admin/` 已返回 404），密码以 PBKDF2 哈希保存在服务器 `/path/to/admin.env`，代码和页面里没有明文

> 单文件版直接离线打开时，场景和钓鱼可用，但背包数据不可用；线上 `https://rmqiu.top/` 使用服务器背包。

## 技术说明

- Three.js r170，WebGL2
- 所有几何体由 `BoxGeometry` / `CylinderGeometry` / `ConeGeometry` / `ShapeGeometry` / 自定义 `BufferGeometry` 生成
- 木纹、木瓦、石材与地面纹理由 Canvas 2D 程序化绘制
- 烟雾和萤火虫使用自定义 `ShaderMaterial` 点精灵
- 水面使用自定义 `ShaderMaterial`：波纹、菲涅尔、月光高光与浮标涟漪全部在片元着色器中计算
- 钓鱼状态机：`idle → casting → waiting → bite → caught / missed`，浮标抛物线、鱼线垂度、鱼跃和落水粒子都由代码驱动
- 背包数据：Python 标准库 + SQLite，服务端 HttpOnly Cookie 用户身份，渔获逐条入库；展示窗口 30 天，存储保留按 6/3/1 个月分层清理
- 背包面板直接渲染服务端数据：鱼获清单、鱼种统计、称呼；渔获榜使用独立面板
- 第一视角相机：从渔夫头部取眼位，隐藏头部、平滑过渡到第一人称；钓起鱼后平滑返回进入前的机位
- 昼夜切换通过颜色、雾密度、灯光强度与材质自发光平滑插值
- 访问 `?shot=1` 可以得到固定构图、停止动画的静态渲染模式，便于截图
